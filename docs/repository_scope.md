# Repository scope

The repository provides analysis utilities, aggregate results, workflow notebooks,
configuration examples, and synthetic-data checks for the liver tumor study.

For the research question and evaluation design, see [scientific scope](scientific_scope.md).
For what can be rerun, see [reproducibility](reproducibility.md). The
[documentation index](README.md) links to methods, results, and dataset access.

Patient-linked artifacts, manuscripts, and checkpoints are outside this release.
Their handling is described in [privacy and data boundaries](privacy_and_data_boundary.md).
Repository-authored materials use the [MIT License](../LICENSE); dataset licenses are separate.
